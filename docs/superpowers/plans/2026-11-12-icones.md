# Ícones (Visuais 2, parte 1) — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gerar os 58 ícones da spec no PixelLab e ligá-los nas telas, na corrida e no wiki, sem mudar nenhuma regra do jogo.

**Architecture:** Um catálogo único (`prototype/tools/icones-catalogo.mjs`) alimenta o lote novo do script do PixelLab, a folha de conferência, os testes e o wiki. O jogo só conhece os nomes dos arquivos: usa `iconeHtml` (HTML) e um cache de imagens no `RaceFx` (canvas), sempre com a reserva de hoje quando o ícone falta.

**Tech Stack:** JS ES5 em `prototype/src/` (UMD, sem dependências); ferramentas em Node ESM (`prototype/tools/*.mjs`); Playwright já instalado para o `ui-test.mjs`; PixelLab API v2 pelo proxy.

**Spec:** `docs/superpowers/specs/2026-11-12-icones-design.md`

## Global Constraints

- Branch `claude/visuais-2`. Commits pequenos, no imperativo, em português, com o trailer da sessão.
- Nada de dependências novas (npm etc.).
- `prototype/dist/` e `docs/wiki.md` só saem do build (`node prototype/build.mjs`), nunca à mão; commitar junto com o `src/`.
- Código de `prototype/src/` em ES5, como o resto do arquivo.
- Não mudam: `data.js`, `sim.js`, `breed.js`, `gear.js`. A corrida dá o mesmo resultado (é só desenho).
- Nada de `Math.random`.
- **Geração paga só com a confirmação explícita do Vinicius no momento de rodar**, teto `--teto 100`.
- Toda geração entra em `docs/memoria/assets.md` (o script registra sozinho).
- Ícone: `alt=""`, com o texto ao lado; sem o arquivo, volta a reserva de hoje (texto, símbolo ou desenho em código).
- Na corrida, o ícone só é desenhado quando ocupa pelo menos 16 px do canvas (`lado × S ≥ 16`).
- `<option>`, `title` e `aria-label` não levam símbolo: usam palavras ("Macho", "2 de 3 estrelas").
- Antes de dizer que terminou: `./scripts/check.sh` e mostrar o resultado.

## Review Focus

1. **Um ícone faltando** (geração falhou ou recusado): a tela mostra a reserva daquele item e o ícone dos outros, sem imagem quebrada. Teste na Task 3.
2. **Celular de 360 px:** o cartão de skill com ícone de 32 px não cria rolagem horizontal. Teste na Task 3.
3. **Skill sem id no balão** (`skillId` nulo, skill que não está no catálogo): a corrida usa o ícone em código, sem exceção. Teste na Task 4.
4. **Imagem ainda não carregada** no canvas: fica o desenho de hoje até carregar. Teste na Task 4.
5. **Link de imagem quebrado no `docs/wiki.md`** (arquivo renomeado ou faltando): o teste do wiki acusa. Teste na Task 5.
