# Menu de abas — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a página única com rolagem longa por uma casca com cabeçalho fixo, barra de 5 abas (Estábulo · Correr · Expedição · Haras · Loja), tela própria por montaria (Status / Skills / Equipamento) e tela de Perfil, sem mudar regra de jogo.

**Architecture:** Tudo dentro do `prototype/src/game.js` atual (IIFE, telas em strings HTML, handlers por `data-acao`). `render()` passa a envolver o conteúdo das telas de aba e sub-tela com `appTopoHtml()` e `appAbasHtml()`; um mapa `SCREEN_KIND` classifica cada tela (`aba` / `sub` / `full`) e dirige `go()`, `isRoot()` e o `popstate`. A tela Equipamento vira a sub-aba Equipamento da tela da Montaria (`ui.montaria.equip` herda os campos de `ui.equip`). CSS novo em `prototype/src/game.css` (barra embaixo até 899 px, coluna à esquerda a partir de 900 px).

**Tech Stack:** HTML/CSS/JS puro, ES5 em `prototype/src/` (`var`/`function`; sem `const`/`let`/arrow/template string/`includes`/`find`/`Set`/`Object.assign`), Playwright em `prototype/tools/ui-test.mjs` (JS moderno), build por concatenação (`node prototype/build.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-08-menu-abas-design.md` (autoridade).
